# Sentiment Analysis using Machine Learning

## Project Overview

This project implements a machine learning-based sentiment
analysis system using TF-IDF feature extraction and Logistic
Regression.

## Model

The final model selected for deployment is Logistic Regression.

## Features

- Text preprocessing
- TF-IDF feature extraction
- Logistic Regression classification
- Streamlit web interface

## Deployment

The application is deployed using Streamlit Community Cloud.
